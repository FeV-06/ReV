# Handover

[Handover](https://github.com/PinnacleCryptNG/handover) is a public hackathon repository that demonstrates chat-based exit interviews. Its agents ask the departing teammate questions, check answers against code, and help the successor pick up work. The repository's open-source license was not verified.

**ReV application.** Use interviews to fill gaps the existing Git and Slack evidence cannot answer. Add interview answers as attributed evidence for review, and distinguish a teammate's recollection from facts supported by the repository.

**Evaluation.** Give the departing engineer an undocumented rollout step and a recollection that conflicts with a runbook. Check that the workflow asks a specific question, flags the conflict, and leaves the reviewer a clear decision.
