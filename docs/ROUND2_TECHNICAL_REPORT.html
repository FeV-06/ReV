1. Executive Summary & Core Mission

When an experienced engineer leaves a software team, they take weeks of undocumented architectural decisions, recovery procedures, and edge-case warnings with them. Traditional handovers fail because static markdown docs become stale within days, and free-form chats suffer from severe hallucinations.

ReV (Relaying to Everyone Virtually) solves this crisis by transforming fragmented commit histories, Tree-Sitter AST code symbols, and Slack discussions into an evidence-linked, human-verified developer handover. ReV enforces mathematical citation integrity: every claim must cite an exact substring from an authorized source artifact.

2. System Architecture: The Three-Tier Local-First Model

ReV is engineered as a hybrid local-first system that decouples native CPU-bound code analysis from client presentation and persistent team synchronization:

1. Headless Daemon :3078

Node 22+ background service bound to loopback. Owns persistent PGlite relational storage, orchestrates Git watchers, and executes native Rust core tasks.

2. Web Dashboard :3077

Next.js 16 / React 19 UI following Google’s Material 3 Expressive tokens. Features a 4-stage screen-advancing Studio and Successor Reader.

3. VS Code Extension IDE Native

Dual-bundle extension (Node host + Browser IIFE) embedding the shared React Team Sync panel and workspace-scoped telemetry inside the developer's editor.

Native Rust Core Engine (crates/rev-core) High Performance

Compiled native binary that executes Tree-Sitter AST symbol parsing (TypeScript, Rust, and Python fallback), git blame ownership and churn heuristics (analyze_local_risk), and verifies verbatim citation quotes before generating candidates.

5. Transparent Operational Disclosures ("What Does NOT Work Yet")

Transparency Notice: ReV is an evidence-backed product. Below is the honest, unvarnished status of work-in-progress boundaries:
  • Multi-Tenant Route Authorization Gating: While the isolated Supabase RLS and SQL membership suites pass 38 unit tests, legacy bulk sync is permanently disabled (HTTP 403) and team sync network calls fail closed until per-user route authorization is completely wired across every endpoint.
  • Live Slack OAuth Configuration: Connecting a live Slack workspace requires pre-configured OAuth bot client credentials. For zero-config evaluation, ReV provides full synthetic ZIP archive ingestion.
  • Unauthenticated GitHub API Bounds: Without a configured GitHub personal access token (REV_GITHUB_TOKEN), public repo imports are constrained by GitHub’s 60 requests/hour IP rate limit.
  • Deep Reasoning Latency: Synthesizing comprehensive handovers with deep reasoning models (e.g. gemini-3.8-flash-high) takes 45–90 seconds over large symbol trees. The UI provides native progress indicators, but instant evaluation is accessible via the synthetic sample.
