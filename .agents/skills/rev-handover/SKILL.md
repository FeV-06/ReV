# Handover research for ReV

Use the [research note](../../../docs/research/handover.md) when designing an interview or successor onboarding workflow.

- Generate questions only for gaps that change what the successor needs to do, such as an undocumented rollout step or an unconfirmed backup owner.
- Separate statements supported by code from interview answers and unresolved claims. Keep the speaker and source visible for human review.
- Verify licensing separately before reusing source code. Use the public project to study workflow behavior while its reuse license is unverified.
