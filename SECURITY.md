# Security

ReV is an early single-operator local prototype, not a hardened multi-user service. Do not expose it publicly or rely on it to automatically verify recipient permissions. Treat source material and model responses as untrusted and review the final handover.

A private vulnerability-reporting channel has not yet been configured. **Before publishing this repository**, the owner must add a real private contact or enable GitHub private vulnerability reporting. Do not include credentials or sensitive project data in public issues.
